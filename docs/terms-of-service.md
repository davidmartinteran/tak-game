## 2. Description of Service

TAK Game is a digital implementation of the abstract strategy board game TAK, designed for two players. The App provides:

- Digital game board with multiple size options (3×3 to 8×8)
- Three types of game pieces: flat stones, walls, and capstones
- Move validation and game rules enforcement
- Victory detection
- Game state saving and loading
- Move history with undo/redo functionality
- Haptic feedback (optional)
